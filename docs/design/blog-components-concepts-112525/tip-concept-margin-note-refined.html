Multiple Tips in One Article

Research

First, I ask the agent to research whatever it is we're trying to accomplish, provide options where applicable, and outline pros and cons.

Tip

There are no dumb questions! Ask the agent to clarify anything.

This can happen at the beginning of a project when trying to determine the feasibility of a particular feature or idea, or when trying to debug a complex or tough-to-solve issue.

Plan

After I review the research and ask any questions I have, I ask the agent to create a phased project plan with success metrics.

Tip

Always save the research and planning docs as .md files.

If it's a smaller bug and the fix is only a few lines of code, I'll skip the planning phase. Once I've reviewed the research, I ask the agent to create a phased project plan.

Build ↔ Test

Now that we've started building, I compare what we're building against the success metrics to determine when is the best time to test.

Pro tip

Fix failures right then and there — don't let them pile up.

If you discover failures and improvement areas during the build process, I like to fix them right then and there. The important part is that you and the agent get a chance to test and measure success.
