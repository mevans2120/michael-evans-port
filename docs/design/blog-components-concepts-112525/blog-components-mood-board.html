Design Principles

Hierarchy

Tips should enhance content without disrupting reading flow. Example prompts should stand out as actionable takeaways.

Accessibility

All components maintain 4.5:1 contrast ratio minimum. Focus states visible. Semantic HTML structure.

Consistency

Components use existing design tokens: border-radius, spacing scale, transition timing. Extend, don't reinvent.
