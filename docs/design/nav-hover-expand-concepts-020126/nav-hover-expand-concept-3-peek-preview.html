Concept 3: Peek Preview

Three-state system: Collapsed → Peeking → Expanded. Hover shows labels in a preview state; chat requires explicit expansion.

  • Collapsed (81px): Icons only
  • Peeking (180px): Labels visible, "Expand for Chat" hint
  • Expanded (320px): Full nav + chat input
  • Peek auto-collapses on leave; expanded persists
Peek Preview: Progressive disclosure - hover shows just enough to navigate, click unlocks the full experience with AI chat.
