# Archived chatbot documentation (October to December 2025)

The documents in this folder describe the retired vector-database design for the portfolio chatbot: a Supabase Postgres instance with pgvector, Google text embeddings, hybrid semantic and keyword search, webhook-driven smart sync, and the admin dashboards that monitored it. That Supabase project no longer exists and the code these documents refer to has been deleted from the repository, so none of the setup, ingestion, or troubleshooting steps here will work. They are kept for history only. For why the design was replaced, read `../../chatbot-functionality-audit-2026-10-09.md`. For the current whole-corpus, prompt-cached design and how it was built, read `../../plans/2026-10-09-chatbot-remediation.md` and `../../../src/lib/chatbot/README.md`.
